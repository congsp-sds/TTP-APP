# 🏭 Smart Factory Management System

Open-source Manufacturing & Inventory Management System  
Designed for small–medium factories (LSX, Outsourcing, Inventory)

✨ React + ASP.NET Core + SQL Server

## 🚀 Features

✔ Production Orders (LSX)  
✔ Outsourcing (Gia công)  
✔ Warehouse Documents (Nhập / Xuất)  
✔ Inventory calculation (no manual stock)  
✔ Role-based access control  
✔ Excel import  
✔ QR Code lookup  

## 🧱 Tech Stack

Frontend:
- React + TypeScript
- Vite
- TailwindCSS

Backend:
- ASP.NET Core
- Dapper
- SQL Server

DevOps:
- Docker
- GitHub Actions

## ⚡ Quick Start

### 1. Clone repo
git clone https://github.com/yourname/smart-factory-management-system.git

### 2. Run with Docker
docker-compose up

### 3. Open browser
http://localhost:5173
