# \# 🏭 Smart Factory Management System

# 

# This repository contains:

# 

# \- apps/frontend  → React UI

# \- apps/backend   → ASP.NET Core API

# \- apps/template  → Quick start demo

# 

# \## Quick start

# cd apps/template

# docker-compose up

# 

# 🚀 Features

✔ Production Orders (LSX)  
✔ Outsourcing (Gia công)  
✔ Warehouse Documents (Nhập / Xuất)  
✔ Inventory calculation (no manual stock)  
✔ Role-based access control  
✔ Excel import  
✔ QR Code lookup

## 🧱 Tech Stack

Frontend:

* React + TypeScript
* Vite
* TailwindCSS

Backend:

* ASP.NET Core
* Dapper
* SQL Server

DevOps:

* Docker
* GitHub Actions
